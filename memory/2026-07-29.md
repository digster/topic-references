## Verification notes (new gotchas worth keeping)
- **`cs.huji.ac.il` sits behind a JS bot-challenge**: it returns **HTTP 200 with an obfuscated
  challenge script or a "Something went wrong" page** to `curl`, and blank to `WebFetch`. The book
  is real and live — proven by `WebFetch` pulling the full **449-page PDF**, whose first page reads
  *"Please link to: http://www.cs.huji.ac.il/~shais/UnderstandingMachineLearning"*. Linked the
  landing page the authors ask for. Another instance of "200 means nothing" from the last session.
- **Playwright cannot reach external hosts here.** The container routes outbound HTTPS through the
  agent proxy, which Chromium doesn't use, so every external `page.goto` fails with
  `ERR_CONNECTION_RESET`. External URLs must be verified with `curl`/`WebFetch`; Playwright is for
  the local site only (run it with the proxy env vars unset and `NO_PROXY='*'`).
- **The bundled Chromium is build 1194, but a fresh `uv --with playwright` pulls a client expecting
  1228.** Do **not** run `playwright install`. Launch with
  `executable_path="/opt/pw-browsers/chromium-1194/chrome-linux/chrome"` and `--no-sandbox`.
- **`pypdf` under plain `uv run` crashes** (`_cffi_backend` missing — the system `dist-packages`
  leaks in). Use `env -u PYTHONPATH PYTHONNOUSERSITE=1 uv run --isolated --with pypdf`. This is the
  fastest way to prove a PDF is the paper it claims to be; poppler/`pdftotext` is **not** installed,
  so the `Read` tool can't render PDFs either.
- Confirmed still true from last session: `github.com` 403s to `curl`, `oreilly.com` 403/000s,
  YouTube 429s (use `oembed` — but it starts answering `Unauthorized` after ~6 rapid calls, so space
  them out; playlist titles can also be read from the page `<title>` with a browser UA).

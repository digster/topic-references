## Resources curated (all URLs web-verified live this session)
- **Books:** *Grokking Algorithms* 2e (Bhargava); *Open Data Structures* (Morin, free CC-BY);
  *The Algorithm Design Manual* 3e (Skiena); *Algorithms* (Erickson, free); *CLRS* 4e (MIT Press).
- **Papers:** Sleator & Tarjan *Self-Adjusting Binary Search Trees* (JACM 1985);
  Bentley & McIlroy *Engineering a Sort Function* (1993).
- **Articles:** Big-O Cheat Sheet (Drowell); basecs (Vaidehi Joshi); Joshua Bloch's
  *Nearly All Binary Searches and Mergesorts Are Broken* (Google Research, 2006).
- **Videos:** Abdul Bari's *Algorithms* playlist; MIT 6.006 lecture videos (Spring 2020).
- **Courses:** Princeton *Algorithms* Part I + Part II (Coursera, both free); the algs4 booksite;
  MIT 6.006 full OCW course; *Algorithms Illuminated* (Roughgarden).
- **Tools:** VisuAlgo; USF Data Structure Visualizations (Galles); CSES Problem Set.
- **Further reading:** *Competitive Programmer's Handbook* (Laaksonen); CP-Algorithms;
  MIT 6.851 *Advanced Data Structures* (Demaine); Okasaki's *Purely Functional Data Structures*;
  Knuth's *TAOCP*.
